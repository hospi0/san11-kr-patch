## 적용 방법

원본 `Sangokushi 11 with Power-Up Kit (Japan).iso` (MD5 `E7F0998FFC3780906728FA47A6CF4595`) 에
동봉한 xdelta.exe(xdelta3) 로 적용합니다.

```
xdelta.exe -d -s "Sangokushi 11 with Power-Up Kit (Japan).iso" "패치 파일.xdelta" "결과 파일.iso"
```

예전 버전의 세이브스테이트는 쓰지 말고 새로 부팅해 주세요.

이 저장소에는 도구·번역 텍스트만 있습니다(ROM·빌드 결과물 없음).
