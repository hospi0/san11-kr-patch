### 확정된 설계 (실기 검증)
- **인코딩**: 한자 코드포인트를 한글 운반체로 사용. 완성형 2,350자 ↔ 한자 SJIS 코드(오름차순) 앞 2,350개. **SJIS→슬롯 테이블도 실행파일 코드도 안 건드린다** — 그 슬롯의 그림만 한글로 칠한다. 한자 풀 3,442 → 1,092 여유. 가나·구두점·전각영숫자 등 331자는 보존.
- **공백 = 반각 0x20 (1바이트)**. 전각공백(0x8140)은 2바이트인 데다 한국어엔 시각적으로 너무 넓다.
- **폰트 = 바탕체, 잉크높이 18px, 합성굵기 0.7**. 원본 게임 폰트가 명조체라 같은 계열로 맞춘 것.
- ⚠️ **미번역 한자 텍스트는 한글 가비지가 된다**(설계대로): 「新しくゲームを始めます」→「옇しくゲームを뽕めます」. 한자를 쓰는 텍스트는 전량 번역해야 한다.

### 핵심 수치
- **글리프 예산 = 정확히 3,773자** (SJIS→슬롯 테이블 전단사). 한글 KS X 1001 2,350자 + ASCII + 기호를 넣고도 여유.
- **폰트 = `s11pkres.bin` 파일오프셋 0x49810** (엔트리 idx=2). 4bpp 20×20, **224 B/글리프**(픽셀 200 + 패딩 24), 슬롯=SJIS 오름차순.
- **코드포인트 리맵 레버 = `SLPM_667.01` 파일오프셋 0x4389E0** (SJIS→슬롯 u16 테이블).
- 두 파일 다 **크기를 유지하면 ISO에 in-place 덮어쓰기 가능** → LBA·디렉토리·2GB 무비 무손상.
- **번역 볼륨 = 산문 382,511자(~765KB) 이상**. 무장 로스터·UI·반각 카타카나가 빠진 **바닥값**이다.
- ⚠️ **가이지 필수**: `龐統` `許褚` `賈詡` `公孫瓚` `鄴` `下邳`는 **cp932에 없다** → 게임이 가이지(≥0xF0B0)로 그린다. 그 슬롯은 고유명사에 필요하므로 **한글 운반체로 회수 금지**.
- ⚠️ **아카이브 꼬리 여유 = 0** (빈틈없이 꽉 참). 성장 예산은 엔트리별 섹터 패딩 9.2MB뿐이고 **파편화**돼 있다(중앙값 1,056 B/엔트리). 자기 섹터 경계까지는 공짜, 넘으면 즉시 오버플로.

## 에뮬레이터 / 동적분석
- PCSX2 사본: `C:\claude\utils\pcsx2` (원본 `D:\hospi\pcsx2`는 건드리지 않음). BIOS = `scph10000.bin` (**Japan 0100JC**).
- 부팅: `pcsx2-qt.exe -fastboot -statefile <p2s> -- "<iso>"`. 게임 CRC = `DB88858E`.

## 선례
삼국지11 본편은 PC 공식 한국어판 존재, PUK는 정발 무산되었으나 **비공식 PC 한글패치(2018 스팀)** 존재 → 번역 참조원 + 엔진 한글 렌더 입증. 단 PS2는 다른 빌드(MIPS)라 자산 직접이식 불가, 번역 참조로만 활용.
