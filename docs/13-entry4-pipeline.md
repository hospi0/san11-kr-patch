## LS11 포맷 (tools/ls11.py 가 정본)

출처: 사용자 제보 `github.com/tzengyuxio/kaodata` → `dekoei/ls11.py`. 의존성 없이 재구현 + 오라클 검증.

```
0x000 "LS11"(또는 "Ls12") + 0패딩 12B
0x010 256B 사전 = 빈도순 리터럴 사전 (30블록 공유)
0x110 (압축, 원본, 오프셋) × N — 전부 u32 빅엔디안, `00000000` 4B로 종료
0x27c 블록 데이터  (PS2 entry4 = 30블록 / PC msg = 1블록, 헤더 288)
```

**알고리즘 = 보편부호(Elias-gamma 변형) + LZ77. 허프만 아님.**

```
코드: 1비트씩 읽어 0이 나올 때까지 센다(=len) -> len비트 MSB-first로 factor
      code = (1<<len) - 2 + factor          # 비용 = 항상 2*len 비트
      len=1 -> 0..1   len=2 -> 2..5   len=3 -> 6..13   len=8 -> 254..509
해석: code < 256  -> 리터럴 = dictionary[code]
      code >= 256 -> 매치 거리 delta = code-256, **다음 코드**가 길이 = 3 + code
```

- ★블록별 무압축 통과: `압축크기 == 원본크기`면 그대로 복사(전역 플래그 아님)
- ★★**안전 상한 = 거리 8191(2^13-1, 게임 링버퍼 8KB) / 길이 512** — **원본이 쓰는 범위 전수 측정**으로 확정,
  실기로 검증됨. ⚠️안 걸면 내 인코더가 거리 70,235까지 뿜고, 우리 디코더는 받아줘서 **왕복 테스트가 거짓 통과**한다.
- ★`max_chain=1024` (64에서 올림) → entry4 −2,085 B. 4096은 이득 없음(포화).

**검증**: 30블록 디코드+재압축+되읽기 30/30 · block23가 RAM 덤프와 바이트 일치 · **실기 통과**
(원본 내용 재압축본으로 부팅 → 환경설정·무장열전 긴 문단 정상).

## 번역 실무

- ★**`gaiji_map.py`에 가이지 48자 비정표**(0xf040~0xf0a9). `{BTNxx}`를 풀어 한글로 쓸 것:
  `{BTN6d}`=鄴→**업** · `{BTN4c}`=龐→**방** · `{BTN40}`=瓚→**찬** · `{BTN49}`=詡→**후**
  ⚠️`{BTNae}`(史 태그)·`{BTNaf}`(演 태그)·`{BTNb8}`이상(PS버튼)은 가이지 아님 → **그대로 둘 것**
- ⚠️**전각 공백(`　`) 유지** — 원본이 `191年2月　虎牢関の戦い` 정렬용으로 쓴다.
  `help_compress.compress`는 이걸 반각으로 바꾸므로 **entry4엔 그대로 쓰면 안 된다**.
- `よろしいですか？` → 「계속할까요?」(세션5 결정)
- ⏸**어미 조립 `{01}Cxx` 있는 82개는 번역 보류** — `終わ{01}Cu{01}` = 어간+[조립 어미].
  한국어는 어간을 못 자른다. entry3의 0~415 조립테이블 재설계가 선행돼야 함.

## ★잠복 버그 (세션8이 라운드트립 게이트로 검출)

`help_codec.encode`의 TOKEN_RE에 **생 제어토큰 `{05}{04}{01}`·`{ESCxx}`가 없어서** 리터럴 ASCII
`7b 30 35 7d`로 나갔다. 게이트를 걸자 **9,873개 전부 실패**. 고친 뒤 idx=3 98.4% / entry4 98.5%.
⭐출하된 idx=3가 안 밟은 건 **운**이었다(split_pad가 앞뒤 05/00을 먼저 떼어냈고 번역구역엔 중간 제어코드가 없었음).

★**ESC 소실만은 봐준다**(`extract_e4._same`): ESC는 반각 가나 렌더 모드 스위치라 한국어엔 안 나온다.
**ESC 외의 차이는 절대 봐주지 말 것.**
