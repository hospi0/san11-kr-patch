# 04 — 다음 세션 재개 계획

## 현재 위치
**타당성 관문 전부 통과 + 한글 1자 PoC 통과(2026-07-16).** 기술적 미지수 없음.
남은 것은 본 파이프라인 구현이며, 최대 노동은 기술이 아니라 **번역 볼륨**이다.

## ✅ 한글 1자 PoC — 통과 (2026-07-16)

**실험**: `決`(slot 1061)의 글리프 그림만 한글 "가"로 교체 → 메인 메뉴가 「**가**戦」으로 렌더됨. 사용자 실기(PCSX2) 확인.

- 글리프 생성: `python tools/make_glyph.py 가 C:/Windows/Fonts/malgun.ttf ga.bin preview.png`
- ISO에 심기: `python tools/poke_glyph.py <iso> 1061 ga.bin`  (ISO 오프셋 `0x7c1870`)
- 부팅: `pcsx2-qt.exe -fastboot -- "<iso>"` — ⚠️**세이브스테이트로 부팅하면 안 된다**(옛 폰트가 RAM에 박혀 있어 패치가 반영되지 않음). 반드시 새로 부팅.

**입증된 것**:
- 4bpp 20×20 / 행당 10B / **저니블 = 왼쪽 픽셀** / 인덱스0=투명 / 1~15 안티에일리어스 램프 — 포맷 가정이 전부 맞다.
- 아카이브의 아틀라스 바이트를 바꾸면 **화면 렌더가 그대로 바뀐다** (중간 캐시·다른 사본 없음).
- ISO in-place 바이트 패치로 게임이 정상 부팅·렌더된다.

**PoC에서 일부러 안 한 것**: SJIS→슬롯 테이블(0x4389E0)은 건드리지 않았다. 게임은 여전히 "決을 그려라"라고 지시하고 그 자리의 그림만 한글이다. 렌더 경로 입증에는 이걸로 충분하며, 테이블 수정은 "어느 코드포인트를 한글로 쓸지" 정하는 본 구현 단계의 일이다.

## 본 구현 계획 (PoC 통과 후)

1. **PS2 플랫폼 문서 작성** — 한글패치 스킬에 PS2가 없다. `references/platforms/ps2.md` 신규.
   본 프로젝트 발견(LINK 아카이브, GS 텍스처 아틀라스+동적 글리프 캐시, PSMT4, ISO in-place 패치, PCSX2 동적분석 절차)을 사례로 넣는다.
2. **인코딩 설계** — 3,773슬롯 예산 안에서 한글 2,350 + ASCII + 기호 배치. 어느 SJIS 코드포인트를 한글로 재할당할지 결정 → `0x4389E0` 테이블 재작성.
   - 유리한 점: 게임이 쓰는 SJIS 서브셋만 슬롯이 있으므로, **안 쓰는 한자 슬롯을 대량 회수**할 수 있다.
   - 주의: 무장명·지명에 필요한 한자는 남겨야 한다(삼국지는 한자 고유명사가 핵심).
3. **폰트 생성 도구** — 한글 TTF → 4bpp 20×20 안티에일리어스 글리프 → 224B 피치로 아틀라스 재작성.
4. **LINK 아카이브 추출/재조립 도구화** (`tools/`). 총 크기 유지 조건으로 엔트리 재배치 지원.
5. **텍스트 3종 추출 파이프라인** (UI=실행파일 / 산문=`0000feff` / 대사=`9b046e12` 스크립트). idx=24 튜토리얼 컨테이너 포함.
6. **번역** — PC 비공식 한글패치를 참조원으로. 방대(무장 800+·열전·이벤트·튜토리얼).
7. **빌드·검증** — ISO in-place 패치 → xdelta → PCSX2.

## 핵심 리스크·주의
- 오피코드/종료자 보존 (대사 스크립트). 길이·포인터 관리 (UI 실행파일 in-place).
- **볼륨이 최대 노동** — 기술이 아니라 번역량이 이 프로젝트의 본체다.
- 원본 자산 커밋 금지. 산출물은 xdelta만 남기고 패치된 ISO는 삭제.

## 환경 메모
- ROM: `C:\claude\roms\ps2\Sangokushi 11 with Power-Up Kit (Japan)\` + `…(Japan).iso`
- PCSX2 사본: `C:\claude\utils\pcsx2` (BIOS `scph10000.bin` = JP). 원본 `D:\hospi\pcsx2`는 사용자 것이니 건드리지 않는다.
- PCSX2는 **SendKeys를 무시**한다 — `keybd_event`(P/Invoke)로 F1(세이브스테이트)·F8(스크린샷)을 보내야 먹힌다.
- 콘솔이 cp949라 일본어 출력이 깨진다 → `PYTHONIOENCODING=utf-8`.
